## Go/No-Go 判定論点

### ✅ Go を支持する根拠

1. **trailing_stop は明確に機能** → 核となる exit 戦略は健全
2. **正しい止損率 90.6%** → stop_loss は利益を生まないが正しく機能している
3. **ETF PF 1.311** → ETF 銘柄選択は有効
4. **ledger 品質 VALID** → データ信頼性の前提が整っている
5. **tiered_min_hold 導入済み** → 誤発動 34% の改善策が稼働中
6. **08-20 開始**（07-28 延期決定）→ さらに 3週間の観察期間あり

### ❌ No-Go / 慎重論の根拠

1. **全体 PF 0.704** → 期待値はまだマイナス
2. **07-10 以降 PF 0.099** → 直近パフォーマンスは特に悪い
3. **Stock PF 0.551** → 個別株の選択精度が低い
4. **sector_shock shadow 有効 0件** → A/B 未完了のまま
