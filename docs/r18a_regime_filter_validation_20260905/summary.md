## 結論: **否定的（現行定義のレジームフィルタは今回の期間ではほぼ機能しない）**

2026-04-01以降の109営業日中、リスクオフ該当日はごく少数
（SPY<50SMA: 13日 / SPY<200SMA: 4日 / VIX>20: 8日 / VIX>25: 1日、VIX最大25.78）で、
しかも大半は**ペーパー運用開始（05-12）前の4月初旬**に集中。運用期間中の該当日
（6/26、7/17〜7/30の一部、6/5・6/10・7/29のVIX>20）の翌営業日にエントリーが
ほとんど発生していなかったため、ブロック対象が最大でも9件しかない。

**7月の出血-$85.6kは「リスクオン相場の中」で発生しており**（7月エントリーの大半は
SPY>50SMA・VIX<20の環境）、市場レジームでは説明・回避できない。出血は個別銘柄/
セクター要因（同日実施のセクター上限検証で cap30% が+$31.5k を示した事実と整合）。

## 解釈と示唆

1. **現行定義（指数SMA/VIX閾値）のレジームフィルタは、この5ヶ月の実績に対しては
   価値なし〜微マイナス**。「月次のムラ=市場レジーム依存」という仮説は、少なくとも
   SPY/VIXベースの単純定義では支持されなかった。
2. 出血の説明変数としてはセクター集中（cap30%: +$31.5k）・シグナル品質帯
   （ss[0.85,1.0)除外: +$19.0k）の方が有望。R18-Aを実装する場合も、指数レジームより
   **セクター/銘柄レベルの環境判定**を優先すべき。
3. ただし観測期間中に本格的なリスクオフ局面（VIX>25が持続、SPY<200SMA が持続）を
   一度も経験していないため、「深いベア相場でフィルタが救う」仮説自体は未検証
   （棄却ではなく判定保留）。テールリスク保険としての価値は別途、より長期の
   ヒストリカルデータでの検証が必要。

## 判断（提案）

- **paper A/B昇格は提案しない**（改善効果なし）。R18-Aは「現行定義では効果なし」の
