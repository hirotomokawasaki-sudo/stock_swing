# R11-C 厳密手法での再検証（2026-08-26）

**背景**: 2026-08-26のロードマップ監査で、2026-08-15にR11-Cの4候補（RSI逆張り/
セクター相対強度/決算近接/ニュースセンチメント）を「全滅」と判定した
`r11c_candidate_backtest.py`が、その後R13-Cで確立されたより厳密な検証手法
（t+1約定、point-in-time universe、conservative OHLC exit、slippage）を
一切反映していない旧手法（同日終値約定、コスト無視）だったことが判明。
R13-Cの`r11_backtest_engine_v4.py`（t+1約定+PIT universe+conservative
exit+slippage+gross/sector/cluster cap）を土台に、同じ4候補のフィルターロジック
（変更なし、`r11c_candidate_backtest.py`からそのままimport）を再実行した。

**手法**: `scripts/r11c_v2_rigorous_rerun.py`新規作成。v4の`run_backtest_v4()`と
完全に同一のシミュレーションループ（entry_filterフックのみ追加）を実装し、
`--candidate baseline_check`でv4本家の出力（n=633, WR=0.7125, PF=1.9251,
net=$107,375.5）と完全一致することを確認済み——ラッパーがv4の挙動を忠実に
再現していることを検証済み。

**重要な発見: baseline自体がwalk-forwardで大きく劣化する構造がある**
（PF 3.70→1.04、比率0.281）。したがって各候補の「一貫性」は絶対値ではなく、
baseline自身の劣化パターンとの相対比較で評価する必要がある。

## 個別評価（2026-08-15の旧結論との比較）

### RSI逆張り: 旧結論「baselineと実質差なし」→ **再検証で明確に異なる結果**

- 全体PFはbaseline比+16%（1.9251→2.2371）、win rateも+1.4pt改善
- **walk-forward比率0.502はbaseline(0.281)の約1.8倍**——後半期間（市場が悪化する
  局面）でbaselineがPF=1.04（ほぼ損益分岐点）まで落ちるのに対し、RSI逆張りは
  PF=1.54を維持。「劣化耐性が相対的に高い」という、旧手法では検出できなかった
  パターンが浮上した
- nは633→541（14.5%減）で、母集団縮小によるサンプル希薄化のリスクは小さい

**旧手法との結論の違いの原因**: 旧手法は同日終値約定・コスト無視だったため、
RSIフィルタが除外する「買われすぎで即座に反落する」パターンの収益への影響が
希薄化されていた可能性が高い。t+1約定+slippageで再検証すると、このフィルタの
効果がより明確に現れた。

### セクター相対強度: 旧結論「前半改善・後半悪化で不一貫」→ **同じ結論、より明確に悪化**

- 全体PFはbaselineとほぼ同水準（1.9028 vs 1.9251）
- walk-forward比率0.214はbaseline(0.281)より**さらに悪い**——後半期間でPF=0.887
  （損益分岐点未満）まで悪化しており、旧検証時よりむしろ悪い結果
- 旧結論（「一貫して優れた数値」という基準に未達）は再検証でも支持される

### 決算近接: 旧結論「両期間ともbaselineより悪化」→ **一部訂正が必要**

- 全体PFはbaseline比+20%改善（1.9251→2.3114）——旧検証（悪化）と逆の結果
- ただしn=103は4候補中最小（元の633件から84%減）で、統計的信頼性は低い
- walk-forward比率0.182は4候補中最悪——サンプルが少ない中でのpost-hocな
  好結果である可能性が高く、単純に「改善」と結論づけるのは危険

### ニュースセンチメントpositive: 旧結論「4候補中最も悪い」→ **同様の結論だがやや改善**

- 全体PFはbaseline比で明確に悪化（1.3423 vs 1.9251）——旧結論を支持
- walk-forward比率0.758は4候補中最良（最も一貫）だが、これはデータ期間が
  4ヶ月と短いため両period自体が小さく、統計的な意味は限定的

## 結論（自己検証込み）

**旧手法（2026-08-15）の「4候補全滅」という判定は、少なくともRSI逆張り候補に
関しては再検証されるべきだった**。厳密な手法（t+1約定・PIT universe・slippage・
ポートフォリオレベルcap）で再実行した結果、RSI逆張りフィルタは全体PF改善に加え、
市場悪化局面での劣化耐性がbaselineより明確に優れているという、旧手法では
見えなかったパターンを示した。

一方、セクター相対強度・ニュースセンチメントの「見送り」判定は再検証でも支持される。
決算近接は結果が逆転したが最小サンプルのため結論保留が妥当。

**この結果に対する自己批判（R13-A/Bの教訓を踏襲）**:
- 単一パラメータ（RSI閾値75）でのみ検証。グリッドサーチは未実施——閾値を
  変えれば結果が変わる可能性は排除できない
- 単一のwalk-forward分割（中央値2分割）のみ。R13-Cのrolling walk-forwardほど
  頑健な検証ではない
- RSI逆張り候補についても、これは「paper A/Bに進める根拠が生まれた」という
  意味ではなく、「見送りを覆すに足る新しい証拠が出たので、次のステップとして
  グリッドサーチ・rolling walk-forwardでの再確認に値する」という位置づけ

## 推奨される次のアクション

1. **RSI逆張り候補を最優先で追加検証**: 閾値グリッドサーチ（例: 65/70/75/80）+
   `rolling_walk_forward.py`相当のより頑健な時系列分割で再確認
2. セクター相対強度・ニュースセンチメントは見送り判定を維持（再検証でも支持）
3. 決算近接はサンプル不足のため判断保留、追加データ蓄積後に再評価
