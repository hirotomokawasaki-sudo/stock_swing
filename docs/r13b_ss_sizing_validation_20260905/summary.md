# R13-B1: signal_strength 帯域縮小サイジング反実仮想 — サマリー（2026-09-05）

## 検証対象ルール（反実仮想）

> entry_signal_strength ∈ B のエントリーをサイズ f 倍に縮小していたら、
> 実現PnL・PFはどう変わったか。
> B ∈ {[0.85,1.00), [0.88,1.00), [0.90,1.00)} × f ∈ {0.5（半減）, 0.0（見送り）}。
> **ss == 1.00 ちょうどはフルサイズ維持**（全バンドが 1.00 を含まない半開区間）。

- スクリプト: `scripts/analyze_ss_sizing_counterfactual.py`（読み取り専用、本番設定変更なし）
- 対象: `data/tracking/pnl_state.json` の closed トレードのうち
  `entry_signal_strength` 非 null の **132件**（closed 357件中。記録は08-14以降
  +バックフィル分のみで、母集団に選択バイアスがある点に注意）
- サイジングは **PnL線形スケール（pnl×f）の一次近似**

## 一次近似の限界（明示）

- pnl×f は「同一のエントリー/イグジット価格で株数だけ f 倍」の近似。実際の縮小は
  **資金再配分**（浮いた資金・exposure/sector cap の余裕が他トレードのサイズを変える）
  と**複利効果**を通じて他トレードのPnLも変えるが、いずれも無視している。
- f=0（見送り）でも、当該ポジション不在によるポートフォリオ構成・guardrail状態
  （circuit breaker、reduce_size等）の変化は考慮しない。
- 影響件数が最大でも14件と少なく、**少数トレード依存**（R13-A/R13-A2と同じ脆弱性）。

## ベースライン再計算と過去引用値との食い違い（重要）

2026-09-05時点の pnl_state.json から再計算した分布は、直前セッションで引用されて
いた「5分位で0.88-1.00帯が-$66k（avg -$2,537）、ちょうど1.00は+$23k」と**一致しない**:

| 区分（再計算） | n | net PnL |
|---|---|---|
| ss == 1.00 ちょうど | 46 | **-$38,764** |
| ss ∈ [0.85,1.00) | 14 | -$18,968 |
| ss ∈ [0.88,1.00) | 8 | -$4,523 |
| ss ∈ [0.90,1.00) | 4 | -$1,786 |
| 件数5分位 Q4 [0.8837,1.0000] | 26 | -$30,286（avg -$1,165） |
| 件数5分位 Q5 [1.0000,1.0000] | 27 | -$13,030（avg -$483） |

「高スコア帯が最悪・非単調」という定性的結論は同じだが、**「ちょうど1.00は黒字」は
現データでは再現しない**（ss==1.00 は n=46 で -$38.8k と最大の出血源）。本検証の
バンド設計（1.00 ちょうどをフルサイズ維持）はタスク指定通りに実施したが、
この前提数値の食い違いは9/8レビューで判断材料にする際に必ず考慮すること。
（signal_strength 付き132件コホート全体: net -$83,465 / PF 0.461）

## 読み方・キーファインディング

1. **Net PnL は全バンド×fでプラス方向**だが、規模とPFの動きはバンドで大きく異なる。
2. **[0.85,1.00) だけが実質的な改善**（全期間 +$9.5k〜+$19k、PF 0.461→0.482〜0.507、
   直近コホートでも PF 0.562→0.598〜0.643）。ドライバーは
   FTXL -$6,706 / CHPX -$6,346（いずれも**08-24半導体セルオフのstop_loss**）、
   LRCX -$2,617、NOW -$2,459/-$2,333、META -$1,936 の負けの縮小。
3. **[0.88,1.00) / [0.90,1.00) は Net 微増だが PF はむしろ悪化**
   （0.461→0.458 / 0.451）。狭いバンドでは HPQ +$4,199（trailing win）の縮小＝
   機会損失が負けの縮小に拮抗するため。「高スコア帯の縮小」は**バンドを狭めるほど
   効果が消える**＝しきい値0.85付近の少数トレードに依存した結果。
4. 機会損失の内訳は上表「影響中の勝ち」列の通り（f=0.5 で勝ち額の半分、f=0.0 で
   全額を失う）。最大の単一機会損失は HPQ +$4,199（[0.90,1.00) 帯にも含まれる）。
5. [0.85,1.00) の改善の相当部分（FTXL/CHPX -$13.0k）は 08-24 半導体セルオフの
   同日決済3件に集中しており、**セクター集中の問題と交絡**している
   （同日実施のセクター集中上限反実仮想 `docs/r13_sector_cap_validation_20260905/`
   と合わせて読むこと）。

## 判定

- 影響件数 n=14（最狭バンドでは n=4）の一次近似であり、R13-A/B が確立した
  「PF/PnL 推定には attributable 30〜90件以上」という基準に遠く及ばない。
- 方向性としては [0.85,1.00) 帯の縮小のみ一貫してプラスだが、少数トレード・
  セクターイベント交絡のため、**単独で昇格を後押しする頑健なエビデンスとは
  言えない**。
- **paper A/B 昇格はユーザー判断待ち**。実装・config変更は一切行っていない。
