## 🚨 **重大な発見: Broker Equity と pnl_state.json の不一致**

### 問題

| 項目 | 金額 |
|------|------|
| **Broker の実際の equity** | **$1,037,008** |
| **Broker の実際の P&L** | **+$37,008** |
| **pnl_state.json の確定 P&L** | **+$115,477** |
| **差額** | **-$78,469** |

### 原因

1. **Alpaca Paper Trading API のバグ**
   - 異常な entry/exit 価格を記録（10-50% 乖離）
   - 過大な P&L が計上されていた

2. **私たちの修正**
   - Yahoo Finance の市場価格で pnl_state.json を修正
   - cumulative_realized_pnl: $115,477

3. **Broker 側の状態**
   - Broker の実際の取引履歴は修正されていない
   - Broker の equity: $1,037,008（実際の値）
   - **Alpaca が何らかの修正を実施した可能性あり**

### 結論

**2つの真実が存在:**

1. **Broker の公式 P&L**: **+$37,008**
   - Alpaca Paper Trading account の「公式」な値
   - 異常な entry/exit 価格による影響を含む
   - または、Alpaca が異常取引を修正した後の値

2. **修正後の理論 P&L**: **+$115,477**
   - Yahoo Finance の実際の市場価格で修正
   - より正確なパフォーマンス評価
   - pnl_state.json に記録
