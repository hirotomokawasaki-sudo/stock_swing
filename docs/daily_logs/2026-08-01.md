- 4本の稼働中 cron job（premarket / market_open / midday / market_close）に
  `ENTRY_FILTER_PF_GATE_SKIP_SYMBOLS=AMD,HPE` を設定

    実際に稼働中の4本の cron job はこのラッパースクリプトを経由せず直接 python を呼んでおり、
    `ENTRY_FILTER_PF_GATE_SKIP_SYMBOLS` が渡っていなかった（実装漏れ）。今回 AMD+HPE 分をまとめて cron job 本体に反映して解消。
- `scripts/cron/run_paper_demo.sh` の `ENTRY_FILTER_PF_GATE_SKIP_SYMBOLS` も `AMD` → `AMD,HPE` に更新（手動実行時の整合性のため）
