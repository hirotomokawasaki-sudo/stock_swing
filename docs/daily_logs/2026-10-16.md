# 2026-10-16 作業ログ

## 10/14損失取引の検証と対策

ユーザーから、10/14の損失取引が一時的な急落への狼狽売りに見え、本質的な損切りに
なっていないとの指摘を受けた。AMAT、CRDO、CIENについて、entry/exit、exit理由、
当日の日中価格、sector benchmark、翌日終値を再構成した。

検証結果は一律の損切り延期を支持しなかった。AMATはexit時点ではsector shockが
未確認の`soft_stop`だったが、翌日まで残り3分の2を保有すると約$2,229悪化した。
CRDOは約-18%のrelative weakness/hard-cap領域、CIENは-16.73%のemergency stopで、
いずれも全量退出を維持すべきケースだった。一方、CIENは既存ロットが約-10%の時点で
買い増しされており、exitだけでなくentry/add側に明確な改善候補があった。

以下を実装した。

- current sessionのreturnをlive quote対直前確定終値で作るセッション整合処理
- stale/missingデータのfail-closed化とsignal_strength代理returnの廃止
- sector benchmarkのbreadth判定
- emergency stopの`stop_loss`分類修正
- 初回3分の1退出＋1セッション確認のshadow-only staged exit
- 既存含み損-3%以下への買い増しを記録するshadow-only guard
- 10/14実データ、翌日反実仮想、no-lookahead、欠損系の回帰テスト

本番の注文・decision filteringは変更していない。forward shadowの証拠が揃うまで
active化しない。詳細は`docs/shock_aware_exit_20261016/README.md`を参照。
