## ✅ R4-A: Signal Strength 飽和原因調査（本日完了）

**根本原因**: `strength = min(momentum / 0.10, 1.0)` の霗和閃値が低すぎる
- momentum ≥ 10% で即座に 1.0 に霗和
- 現在の強気相場（2026）: 半導体/テック株は 60 日間で 15〜30% 上昇
- 結果: BUYの 73% が strength=1.0 に霗和

**修正方針（R4-B 以降に実装）**:
1. Option A (簡易): `min(momentum/0.20, 1.0)` → 20%で霗和、霗和率を約 30%以下に削減
2. Option B (推奨): 多因子スコア（momentum・ volume・ ATR合成）
3. Option C (長期): パーセンタイルランク（履歴データ要）

詳細: `docs/r4a_signal_strength_investigation.md`
