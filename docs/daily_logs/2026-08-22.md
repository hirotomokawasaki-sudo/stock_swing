## Web Console: news-ticker aliases を symbol_registry.yaml 駆動に変更

**発見**: `console/services/dashboard_service.py`の`_link_news_to_decisions()`
内の`ticker_aliases`辞書が、ハードコードされた10銘柄
（MRVL/CIEN/DELL/RBRK/PLTR/AVGO/GOOGL/META/MSFT/AAPL）のみで、実際の
取引ユニバース44銘柄・symbol_registry.yaml登録80銘柄の大半をカバー
していなかった。これは08-21に`src/stock_swing/risk/news_sentiment.py`で
実装した関連度フィルタと同種の問題が、Web console側の「他銘柄記事混入
検知（other_ticker_penalty）」ロジックにも存在していたことを意味する。
例えばLRCXに関する記事がMSFTのニュースフィードに紛れ込んでも、LRCXが
ハードコードリストになければペナルティが一切かからなかった。

**対応**: `_news_ticker_aliases()`を新規実装。symbol_registry.yamlの
descriptionフィールドから動的にエイリアスを生成（企業サフィックス除去は
news_sentiment.pyの`_company_name_aliases()`と同じロジックを踏襲、
src/console境界を跨いだprivate helper importは避けて軽量に再実装）。
JP拡張銘柄の「Advantest Corporation (JP, test equipment)」のような
括弧内注記も除去してから使用するよう対応。

**効果**: エイリアスカバレッジ 10銘柄→80銘柄（symbol_registry.yaml全件）。
今後新規銘柄を追加してもコード変更不要でticker_aliasesに自動反映される。

**テスト**: +6件（alias導出4件、統合テスト2件 — LRCX記事がMSFTニュースに
誤って紐づかないことをEnd-to-Endで確認）。フルスイート: **2059 passed /
2 skipped**（regressionなし）。commit `11388d1`、push済み。console自動
再起動も正常完了。
