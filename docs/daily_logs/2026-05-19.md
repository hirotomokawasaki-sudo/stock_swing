### 3. SIGTERM 原因精査 🔍

**調査結果**:
- OpenClaw Gateway ログ: SIGTERM 送信の記録なし
- Error ログ: プロセス kill の記録なし
- システムレベルでの kill の可能性が高い

**仮説**: macOS システムによる Resource Limit
- Order Submission は CPU/メモリ負荷が最も高い
- 市場の volatility や処理量に依存してランダムに終了
- OpenClaw に記録がない = システムレベルでの制限

**次のアクション**:
- 今夜 23:00 JST の実行で snapshot 記録を確認
- SIGTERM が再発するかモニタリング
- 必要に応じて追加対策（処理の分割、メモリ使用量削減など）
