### 6. Console Dashboard の修正（10:25-10:29 JST）

**問題発見**:
- ポジションタブで `decision_status: stop_loss` と表示されているが、実際は含み益
- 例: AMAT +3.02%, DELL +2.78% なのに `stop_loss` 表示

**原因**:
- 旧アカウント（V2）の decision ファイル（922件）が残っている
- Console は最新20件の decision を見て判断
- 古い stop_loss decision が見つかって誤表示

**対応（Option A）**:
```bash
# 2026-05-12 より前の decision をアーカイブ
find data/decisions -name "decision_*.json" -type f \
  -exec stat -f "%Sm %N" -t "%Y%m%d" {} \; | \
  awk '$1 < 20260512 {print $2}' | \
  xargs -I {} mv {} data/archive/decisions_pre_20260512/
```

**結果**:
- アーカイブ: 922件
- 残存: 3件（V3 開始後の decision のみ）
- すべてのポジションが `decision_status: hold` に修正

**Before / After**:
```
Before:
  AMAT | stop_loss | +3.02%  ← 誤表示
  DELL | stop_loss | +2.78%  ← 誤表示

After:
  AMAT | hold      | +3.02%  ← 正常
  DELL | hold      | +2.78%  ← 正常
```
