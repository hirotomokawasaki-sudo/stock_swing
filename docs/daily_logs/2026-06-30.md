### ✅ 優先2: Post-R1-B attribution 低下の調査・修正（commit b658f7d）

**根本原因（2つのバグ）**

**Bug 1: Partial-fill reason 喪失**
- 1つの sell order が複数 open ポジションを FIFO クローズする場合、paper_demo が 1件目処理後に `delete_exit_reason` を呼ぶ
- 残ポジションを処理する reconcile cron は pending reason が消えていて `broker_fill_unknown` を使用

**Fix**: reconcile partial-fill completion 時に同一 `exit_broker_order_id` の既存 closed trade から reason を継承

**Bug 2: 古い sell order が新規ポジションに誤マッチ**
- timestamp マッチ失敗時の fallback `latest_sell_orders_by_symbol` が古い sell order を返す
- 新規 open ポジションが古い sell order（3日前）でクローズされてしまう

**Fix**: fallback マッチ時に sell order の submitted_at と open ポジションの entry_time を比較し、sell が entry より古ければスキップ（temporal guard）

**遡及修正**
- `KLAC-6218057b`: `broker_fill_unknown` → `trailing_stop`（trade_events で exit_signal_fired を確認）
- `CRDO-e23dd752`: `broker_fill_unknown` → `stop_loss`（同上）

**結果**: Post-R1-B attribution 57.1%（4/7） → **85.7%（6/7）**

残り 1件: `KLAC-87a46701`（06-29T13:36 entry → 06-29T13:45 exit、exit_broker_order_id=42cffcab は06-26の古い order）。temporal guard の今後の運用で新規発生は防止済み。既存エントリは broker audit で要確認（不要緊急）。
