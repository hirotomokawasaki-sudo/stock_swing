## 3. day_start_equity null 問題 → 根本修正（commit `fdab6cd`）

### 根本原因

**Fix 1: `broker.get_account()` はメソッドとして存在しない**
- 正しくは `fetch_account()`
- `AttributeError` が `except Exception: pass` で silent catch され equity=None
- その結果 `source="tracker_estimate"` / `day_start_equity: null`
- startup 時に既に `fetch_account()` で取得済みの `equity` 変数を再利用するよう修正

**Fix 2: 欠損スナップショットが同日に上書きされない**
- 一度 equity=null で書かれると、同日の後続実行でも null のまま使い続けた
- `load_or_capture_day_start` を修正: `missing_fields` があり入力が改善できる場合は再キャプチャ
- 完全なスナップショット（missing_fields=[]）は上書きしない（regression なし）
