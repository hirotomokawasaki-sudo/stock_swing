## R1-A ログ未出力の根本原因調査 → 修正完了

### 根本原因
`paper_demo.py` の `main()` で `logging.basicConfig` が未設定。
Python の仕様上、`basicConfig` なしでは `logger.info()` は "last resort" handler
（WARNING+ のみ通過）に落ちて無音で捨てられる。

### 影響
R1-A で追加した構造化ログ（`exit_signal_fired` / `exit_signal_generated` /
`exit_signals_none`）が cron ログに一切記録されていなかった。

### 修正（commit: c19a6db）
`paper_demo.py main()` に以下を追加：
```python
logging.basicConfig(level=logging.WARNING, format="...", stream=sys.stderr, force=True)
logging.getLogger("stock_swing").setLevel(logging.INFO)
```
- root logger: WARNING（サードパーティライブラリのノイズを抑制）
- stock_swing: INFO（exit_signal_fired 等が記録される）

### 確認
- 560 unit tests passed
- `exit_signal_fired` が INFO で正しく出力されることをユニットテストで確認

### 次のアクション
次回 paper_demo 実行後にログを確認：
- `exit_signal_fired` が出る → Case B / C / D のいずれか（R1-B で修復）
- `exit_signals_none` のみ → Case A（シグナル自体が未発火）
