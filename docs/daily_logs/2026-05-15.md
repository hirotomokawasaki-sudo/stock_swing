## Exit Strategy 問題の調査・解決（20:14-21:28）

### 問題の発見
ユーザーからの質問：「保有期限がMax5日で現状値下がりしている状態で損切りラインの前でマイナス利益で利確して売っているのはどういう判断に基づいているのか」

### 調査結果

#### Phase 1: Exit Strategy の動作確認
- 設定確認: `stop_loss_pct: -7%`, `max_hold_days: 9`, `trailing_stop: 3%`
- 実際の取引履歴: **すべての67件が 1日未満**（平均 0.32日、中央値 0.04日）で exit
- Exit reasoning を確認: decision ファイルに記録されていた（`evidence.notes`）
- 例: TTEQ "Stop loss triggered: -19.23% <= -7.00%"

#### Phase 2: Price Data の不整合を発見
- TTEQ の実際の exit: entry $41.02 → exit $41.16 (**-0.79%**)
- Decision の計算: entry $41.02 → stale price $34.18 → **-16.4%**（誤判定）
- **根本原因**: Feature 計算で使用している price data が **2026-04-22 で停止**

#### Phase 3: 影響範囲の全体調査
**重大な発見**: **すべてのETF symbols（16個）が 2026-04-22 で stale**
```
TTEQ, SOXQ, SOXX, SMH, FTXL, PTF, SMHX, FRWD,
GTOP, CHPX, CHPS, PSCT, QTEC, TDIV, SKYY, QTUM
```

**パフォーマンスへの影響**:

|------|-----|-------|------|
| 総P&L | **-$9,367.59** | +$4,657.32 | **-$14,024.91** |
| 取引数 | 37件 | 30件 | - |
| 平均P&L | -$253.18 | +$155.24 | -$408.42 |

**Price deviation の実例**:
