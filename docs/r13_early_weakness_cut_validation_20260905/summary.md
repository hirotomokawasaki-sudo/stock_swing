# R13-A2: Early Weakness Cut ヒストリカル検証 — サマリー（2026-09-05）

## 検証対象ルール（反実仮想）

> 保有K日目以降の各日終値時点で、**エントリー以来の最高含み益が+2%未満** かつ
> **現在リターンが-3%以下** なら、その日の終値でexit（ハードストップより先に判定）。
> K ∈ {3, 4, 5} の3バリアント。

- スクリプト: `scripts/simulate_early_weakness_cut.py`（読み取り専用、本番設定変更なし）
- 手法: `scripts/simulate_stop_loss_deepening.py`（R13-A、2026-08-23）と同一の
  日次パスリプレイ。trailing_stop → breakeven_stop → **[early_weakness_cut]** →
  stop_loss → time_based の優先順位を `SimpleExitV2Strategy` 自身のメソッドで再現。
  価格取得も同一（yfinance日次終値、ATR%はエントリー時点固定、universe平均は±3日近似）。
- 発火条件がpeak gain < +2%のため、trailing/breakeven（活性化+5%以上）が有効な日には
  構造的に発火し得ない。よって「stop_loss分岐直前」への挿入は仕様の
  「ハードストップより先に判定」と厳密に等価。
- baseline/variant とも現行本番config（2026-09-05時点、volatility_adjusted_stop有効）を
  両側同一適用 → 測定差分は early weakness cut ルールのみを分離。

## 機会損失の要約（このルールの主リスク）

「弱いスタート→その後大化け」のトレードを切り捨てるコストが、全closedコホートでは
早期カットの節約分を圧倒する:

- **AMD 2026-05-12**: K=3でcut -$5,094 → baselineはtrailing_stopで**+$20,275**
  （逸失$25,370、単独で全コホートK=3悪化分の3割）
- PANW 06-04（逸失$14,080）、FTNT 06-04（$8,995）、SOXX/SOXQ/QTUM 05-13〜14の
  ETF群（各$7-8k）、PLTR 07-15（$7,619）、HPE 07-22（$7,344）、MSFT 07-15（$5,864）
- いずれも「数日間ぐずついて-3%以下まで沈んだ後にtrailing_stop圏まで急回復」した
  トレード。ルールの条件（peak<+2% & return≤-3%）はこのパターンを構造的に誤爆する。
- Kを大きくすると機会損失は減る（K=3: 25件$146k → K=5: 11件$74k）が、
  同時に「深いstopを浅く済ませる」便益も減り、全体では依然マイナス。

## 判定

- **全closedコホート（n=295）ではK=3/4/5すべて明確に悪化**（-$34k〜-$85k、PF・maxDDも悪化）。
- 直近コホート（07-16以降）はK=3のみ僅かに正（+$244、実質ゼロ）でK=4/5は悪化。
- attributableコホートのみ全Kで正（最良K=4 +$1,849、PF 1.031→1.091）だが、
  n=43・改善原資はAMZN/QTUM等の少数stop回避で、R13-A（stop深掘り検証）と同じ
  **母集団依存・小標本**のパターン。
- **結論: ヒストリカル検証としては昇格を後押しする頑健なエビデンスなし。**
  paper A/B昇格はユーザー判断待ち（本検証は判断材料の提供のみ）。

## 既知の制約

- 日次終値のみ（イントラデイ・ギャップ・スリッページは表現外）。baseline replayの
  exit_reason一致率は (a) 62% / (b) 84% / (c) 91%。全closedコホートは
  broker_reconstructed起源（entry_signal_strength欠損）の旧トレードが多く
  replay忠実度が相対的に低い点に注意。
- ATR%エントリー時点固定・universe平均±3日近似（先行2スクリプトと同一の制約）。
- 同日エントリー/exitトレード（62件）はリプレイ不能のため除外。
