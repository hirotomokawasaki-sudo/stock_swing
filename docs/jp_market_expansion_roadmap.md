# 日本市場拡張ロードマップ(総合版): トラック優先順位と規律

**作成日**: 2026-09-05(ユーザー指示によりロードマップ化)
**位置づけ**: 日本市場拡張の**親ドキュメント**。既存の
`docs/jp_semiconductor_ai_expansion_plan.md`(2026-08-19、半導体特化)は本書の
**Track 2の特化ケース**として包含する。物理前提(日本株の実売買)は
`docs/broker_migration_ibkr_plan.md`(IBKR移行)を共有する。

**背景**: 現状は米国IT銘柄のみだが、IBKR移行後は日本株等も購入可能になる。

## 0. 大原則(全トラック共通)

1. **勝てていない戦略を新市場に輸出しない。**
   2026-09-05時点の経済性ゲートは NO-GO(直近コホート n=45 / PF 0.530 /
   expectancy -$551、`check_go_no_go.py` economic_viability)。日本市場へ移植して
   よいのは「勝っている・構造的に堅い要素」のみ:
   - trailing exit エンジン(実績 +$176k、勝率81%)
   - ETFローテーションの枠組み(R13-D、shadow安定稼働中)
   - 時差の情報フロー(米国クローズ情報 → 東京オープン)
2. **同一規律**: Phase 1 データ検証 → Phase 2 設計 → Phase 2.5 shadow →
   paper A/B → 経済性ゲート → ユーザー承認後に本配線。米国側と同じ
   fail-closed 運用(ゲートを緩めない)。
3. **セクター集中制約**: 半導体関連連結エクスポージャは equity比 **30%以下** を
   上限予算とし、**日本株の半導体銘柄も同一予算に合算**する。
   根拠: セクター集中上限の反実仮想検証(2026-09-05、
   `docs/r13_sector_cap_validation_20260905/`)で cap 30% のみが全期間 +$31.5k /
   直近 +$12.9k と明確に有効(40%は逆効果)。
4. **購入禁止リスト**: ユーザー提供のインサイダー等禁止リスト
   (`jp_semiconductor_ai_expansion_plan.md` セクション1、9984確定済み)との照合を
   全トラックの Phase 1 段階から実施。検証には含めてよいが、発注直前の
   deny-list(`purchase_restricted_symbols` → `EntryFilterEngine`)配線が
   Phase 3 の必須前提。

## 2. Track 1: JPセクターETFローテーション(R13-D日本版) 🥇

**仮説**: 米国版 R13-D(sector_rotation_v1)と同じモメンタムベースのセクター
ローテーションは、東証セクターETFでも機能し、かつ JPY建て・別レジームのため
ポートフォリオ全体のPF安定化(分散)に寄与する。

**筋が良い理由**:
- `SectorMomentumFeature` / `SectorRotationStrategy` / `SectorRotationStateStore`
  (本番未配線、shadow安定)の再利用度が最も高く、実装コスト最小
- ETFのため個別株インサイダー制約(購入禁止リスト)を構造的に回避
- 個別株リスク(決算ギャップ等)も同時に回避

**対象候補(暫定、Phase 1で流動性検証)**: TOPIX(1306)、日経225(1321)、
NEXT FUNDS 東証17業種ETF(1617〜1633)等。出来高・スプレッド・乖離率を
Phase 1 のスクリーニング項目に含める。

| Phase | 内容 | IBKR |
|---|---|---|
| 1 | yfinance `.T` で日足取得し、17業種のモメンタムランキングをヒストリカル再現。流動性スクリーニング。禁止リスト照合 | 不要 |
| 2 | JPX市場カレンダー・JPY建てPnL・単元口の設計(Track共通基盤、セクション5参照) | 不要 |
| 2.5 | 既存 `log_sector_rotation_shadow.py` と同型のJP版shadowロガー+日次cron(発注なし) | 不要 |
| 3 | IBKR接続後、小サイズ(equity比10%以下)でpaper配線 → 経済性ゲート | 必須 |

**Go基準**: shadow 30営業日以上でランキング安定性・データ欠損なしを確認後、
paper移行はユーザー承認。paper後は米国側と同じ経済性ゲート水準。

## 3. Track 2: US→JPオーバーナイト・スピルオーバーの一般化 🥈

**現状**: 半導体特化版(`jp_semiconductor_ai_expansion_plan.md`)が Phase 2.5
shadow 稼働中(`data/jp_overnight_spillover_shadow_log.jsonl`、2026-08-19〜、
NaNガード修正済み 2026-09-04)。

**本書での方針変更(2026-09-05)**:
- **半導体版の Phase 3(実配線)優先度は「低」に位置づける。**
  理由: 直近の出血源が米国半導体集中(LRCX/INTC/AVGO/NVDA等、8/14以降コホート)
  であり、JP半導体(東エレ・アドバンテスト等)はSOXX相関が高く**同一リスク因子の
  積み増し**になるため(`docs/review_criteria_20260908.md` 総論と整合)。
  配線する場合もセクター上限30%予算の内数。
- **時差エッジ自体は筋が良い**ため、同じ
  `evaluate_overnight_spillover_signal()` 枠組みを**半導体以外のセクターペア**へ
  一般化する:

| USシグナル源(暫定) | JP反応候補(暫定) |
|---|---|
| XLF(金融) | メガバンク 8306 / 8316 / 8411 |
| XLE / WTI(エネルギー) | 総合商社 8001 / 8031 / 8058、INPEX 1605 |
| USディフェンス関連 | 7011 / 7013 等 |
| XLY / 主要テック決算 | JP小売・ゲーム等(候補選定はPhase 1で) |

※ 上記ペアはすべて暫定。**Phase 1 で既存Go基準(相関係数0.4以上 または
方向一致率60%以上)を満たしたペアだけ残す**。購入禁止リスト照合を必ず先に行う。

| Phase | 内容 | IBKR |
|---|---|---|
| 1 | ペア相関スクリーニング(半導体版 Phase 1 の分析コードを流用) | 不要 |
| 2.5 | 通過ペアのみ既存shadowロガーをマルチペア対応に拡張し記録 | 不要 |
| 3 | 半導体版と合算のセクター/因子予算内で配線判断 | 必須 |

## 4. Track 3: JP決算PEAD(決算後ドリフト)スイング 🥉

**仮説**: 日本は決算開示が引け後(15時以降)に集中し、「翌朝ギャップ→数日ドリフト」
の構造が明確(PEADとして学術的裏付けが厚い)。現行システムの平均保有7.3日の
スイング体質・trailing exitと適合する。

**流用資産**: R10(決算カレンダー接続、米国版)、`event_swing_v1` の骨格。

**律速**: TDnet/決算スケジュールの日本側データソース選定(Phase 1)。
Track 1/2 が Phase 2.5 に到達してから着手する(3番手)。

## 6. やらないこと

- **JP半導体個別銘柄のエクスポージャ積み増し**(セクター上限30%の枠外運用)

- **通貨リスク方針未定義のままの本配線**(Phase 2でJPY建てPnL計上方針を先に文書化)
