## 追加分析: ギャップ貫通ストップ × 決算またぎ（直接効果の証拠）

- exit_reason=stop_loss かつ return <= -9% のギャップ貫通: **29件、PnL合計 -$111,018**
  （起票時の概算「約20件」より多い。閾値-9%ちょうど付近の件数差によるもので、
  本スクリプトの直接カウントを正とする）
- **うち保有期間内に決算日を含むもの: わずか1件**（AVGO 06-02entry→06-03決算→06-04
  stop_loss、-$8,619 / -16.3%）。判定不能0件。
- → **ギャップ貫通ストップの主因は決算ではない**（29件中28件は決算と無関係の
  ギャップ/急落）。「stop_lossの出血≒決算またぎ」という当初仮説は棄却。

## 解釈と示唆

1. **効果はプラスだが中規模、かつ主因の説明にはならない**。N=7で全期間+$9.1k
   （総損失-$38.3kの約24%相当）、直近コホート+$4.3k。ただしブロック件数20件のうち
   勝ち10件を同時に失っており、期待値改善はブロック1件あたり約+$456と細い。
2. N=3/5はほぼ効果なし〜微マイナス。**効果の大半はN=7で拾えた4件の大負け**
   （AVGO -$8.6k、ORCL -$4.4k/-$4.8k、RBRK -$4.4k等）に依存しており、
   サンプル依存性が高い。
3. ギャップ貫通29件の-$111kのうち決算由来は1件-$8.6kのみ。ギャップリスクの本丸は
   決算以外（ガイダンス修正・セクター急落・個別ニュース）にあり、対策としては
   R18-C（ATR定額リスクサイジング=1件あたりの被弾額の上限管理）の方が構造的に有望。
4. 実装するなら「決算前N=5〜7日の新規エントリー禁止」は低コスト（機会損失が小さい）
   で負けテールを1本切る保険として妥当。ただしevent_swing_v1（決算前に買う設計）
   とはフィルタ適用スコープを分離する必要がある。

## 判断（提案）

- **単独でのpaper A/B昇格は提案しない**（効果が数件の大負けに依存、多重検定下で
  過大評価リスク）。R18-C設計時に「決算前ブラックアウトN=5〜7」をオプション束
  として含め、R13-C完了後のout-of-sample期間で再検証してから昇格判断する。

## 限界と注意（多重検定）

- 一次近似: ブロックPnLの除去のみ。資金再配分・複利・代替エントリーは未考慮。
  ブロックは勝ち（全期間で+$18.9k分）も消す。
- **本検証は同一closed 357件への反実仮想の重ね掛け（セクター上限・ss帯・early
  weakness cut・R18-A・本件）の一つであり、探索的検証である。いかなる昇格判断にも、
  R13-C完了後のout-of-sample（holdout期間）での再確認を必須とする（R18-D）。**
- yfinance決算日の粒度は「日付」のみ（BMO/AMC不明）。N日の数えはカレンダー日
  （営業日ではない）。
