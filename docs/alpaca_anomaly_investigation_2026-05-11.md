# Alpaca Paper Trading API 異常価格問題の調査と対応

## 📅 日時
- 2026-05-11 10:00 JST

## 🚨 問題の発見
コンソールの概要タブで、トレード結果以外の資金や追加資金が含まれているように見えるという報告を受けて調査。

## 🔍 調査結果

### 1. 累積 P&L の異常
- **PnL Tracker の表示**: $1,011,671.36
- **初期資金**: $100,000
- **Broker equity**: $1,038,978.11
- **実際の gain**: $938,978.11

→ **9.4倍の gain は現実的ではない**

### 2. 根本原因: Alpaca Paper Trading API のバグ

**Broker (Alpaca) が異常な filled_avg_price を返している:**

```
AMD 2026-05-08 17:10:06 SELL 282 @ $443.62  ← 異常 (市場価格は$236前後)
AMD 2026-05-08 15:00:12 BUY  282 @ $435.72  ← 異常
AMD 2026-05-08 14:15:27 SELL 267 @ $435.62  ← 異常
AMD 2026-05-07 15:00:48 SELL 175 @ $414.01  ← 異常
AMD 2026-05-06 14:36:43 BUY  268 @ $407.49  ← 異常
MRVL 2026-05-07 SELL entry=$114 exit=$167 (+46%)  ← 異常
ARM 2026-05-07 SELL entry=$148 exit=$217 (+46%)  ← 異常
NBIS 2026-05-07 SELL entry=$125 exit=$180 (+44%)  ← 異常
```

### 3. 影響範囲

#### 超高リターン取引 (>50%)
- **件数**: 3件（すべて AMD）
- **影響**: $172,000 の異常 P&L
- **対応**: ✅ 削除済み (2026-05-11 10:05)

#### 高リターン取引 (30-50%)
- **件数**: 31件（MRVL, ARM, NBIS, DELL など）
- **影響**: $465,973 の異常 P&L
- **対応**: ⏳ 検討中

#### 削除後の累積 P&L
- **state ファイル**: $839,670.98
- **PnL Tracker 表示**: $1,011,671.36（キャッシュ未更新）

### 4. Alpaca API の問題パターン

1. **Paper Trading 特有の問題**
   - Market order の約定価格が市場価格と大きく乖離
   - 特に売り注文で高値約定が多い

2. **再現性**
   - 2026-05-06 から 2026-05-08 にかけて集中発生
   - AMD, MRVL, ARM, NBIS などで顕著

3. **既存の防御策**
   - `reconcile_orders.py` で 50% 以上の価格変動を拒否（2026-05-08 実装済み）
   - しかし、30-50% の異常は検出できていない

## 🔧 実施済み対応

### 1. 超高リターン取引の削除
```bash
# 2026-05-11 10:05 実行
python scripts/cleanup_alpaca_anomalies_20260511.py

# 結果:
# - 削除: 3件 (AMD の 87% リターン取引)
# - バックアップ: pnl_state_before_alpaca_cleanup_20260511_100506.json
# - 新 cumulative P&L: $839,670.98
```

### 2. reconcile_orders.py の改善（2026-05-08 実施済み）
- 50% 以上の価格変動を拒否
- 無効価格（≤0）を拒否
- デバッグログ追加

## 📋 今後の対応

### Immediate (今日中)
1. **30-50% リターン取引の精査**
   - 市場価格との比較検証
   - 削除の要否判断

2. **PnL Tracker キャッシュのクリア**
   - コンソール再起動
   - または state ファイル再読み込み機能の追加

3. **コンソール表示の修正確認**

### Short-term (今週)
1. **reconcile_orders.py のさらなる強化**
   - 30% 以上の価格変動も拒否（現在は 50%）
   - 市場価格との比較検証を追加
   - リトライ時の価格再確認

2. **定期的な異常データチェックの自動化**
   - 日次で異常リターン（>30%）を検出
   - アラート通知
   - 自動削除（オプション）

3. **Broker API の代替検討**
   - Alpaca の Paper Trading 以外のオプション検討
   - または Live Trading への移行（少額）

### Long-term (今月)
1. **Alpaca への問題報告**
   - 異常価格の事例をまとめて報告
   - API バグの修正依頼

2. **バックテスト環境の構築**
   - Paper Trading に依存しない検証環境
   - 履歴データでの戦略テスト

## ⚠️ 重要な学び

1. **Paper Trading API の限界**
   - Alpaca Paper Trading は実戦環境として不適切
   - 価格精度が低く、戦略の正確な検証ができない

2. **防御的プログラミングの重要性**
   - 外部 API の返り値は常に検証が必要
   - 異常値の早期検出とアラート

3. **データ監査の必要性**
   - 定期的なデータ品質チェック
   - 異常値の自動検出と報告
