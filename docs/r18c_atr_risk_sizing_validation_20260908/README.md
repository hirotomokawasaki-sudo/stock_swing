## 判定

**前向きpaper A/B設計へ進める有力候補**。ただしpseudo-holdoutは事前登録時点ですでに
存在した履歴であり、真のout-of-sampleではない。本検証はactual PnLの線形縮尺で、
同時保有・再投資・qty変更によるfill差を再現しない。したがって本番反映は行わず、
`docs/promotion_governance.md` のpaper A/BとR13-C後OOS再検証を必須とする。
