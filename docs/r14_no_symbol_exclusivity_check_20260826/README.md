# R14 dip-buy: 「1銘柄1ポジション」排他制御を外した本番相当検証（2026-08-26）

**背景**: 同日実施したR11-C RSI逆張り候補の検証で「バックテストエンジンの1銘柄1
ポジション排他制御が戦略効果と混同されうる」というアンチパターンを発見した
（`docs/r11c_rsi_no_symbol_exclusivity_20260826/`）。R14 dip-buyのPhase 1検証も
同じ簡略化（`r14_dip_buy_meanreversion_phase1.py`のLimitations節に「one open
position per symbol」と自己開示済み）を使っており、GO判定（dip-buy PF=1.963 vs
momentum PF=1.854）が同様のアーティファクトに影響されていないか確認した。

**dip-buy特有の懸念**: 逆張り戦略は下落トレンド継続銘柄に対して連日シグナルが
発火しやすい構造的性質があり、モメンタム戦略よりもこの簡略化の影響を強く受ける
可能性が高い（例: NVDAが初日-5%で下落シグナル発火後も下落継続すれば、翌日以降
も理論上シグナルが発火し続けるが、排他制御下では最初の1回しかポジションが
建たない）。本番では（同日確認済み）`RiskValidator.validate()`が
`current_positions`を無視し、`paper_demo.py`も金額上限のみでポジション数を
制限しないため、本番では下落継続中に複数回ナンピン買いが発生しうる。

## 検証方法

排他制御を完全に除去（同一銘柄に複数ポジション同時保有を許可、各lotを独立に
追跡・exit判定）したエンジンで、dip-buy戦略とmomentum戦略の両方を同一条件で
再測定。Phase 1の2つの主要比較（point-in-time universe / full-history）に加え、
Phase1が発見した「チョップ相場局面（2025-11〜2026-03）でのmomentum弱点補完」も
同条件で再検証した。

## 結果

| variant | 指標 | Phase1（排他制御あり） | 本検証（排他制御なし） |
|---|---|---|---|
| PIT universe | dip-buy n / PF | 359 / **1.963** | 1,208 / **1.530** |
| PIT universe | momentum n / PF | 621 / 1.854 | 2,348 / **2.063** |
| full-history | dip-buy n / PF | 1,938 / **1.710** | 7,696 / **1.456** |
| full-history | momentum n / PF | 1,997 / 1.575 | 9,164 / **1.787** |

### (b) チョップ相場局面（2025-11〜2026-03、full-history）

| | dip-buy | momentum |
|---|---|---|
| n | 2,108 | 1,101 |
| profit_factor | **1.1811** | **0.6414** |
| net_pnl | **+$85,758.32** | **-$118,092.99** |

## 結論: 判定は分かれる（混在結果、正直に報告）

### (a) 全期間比較: 逆転（優位性は支持されない）

排他制御ありの条件ではdip-buyがmomentumをわずかに上回っていたが（PIT: 1.963
vs 1.854、full-history: 1.710 vs 1.575）、排他制御を除去した本番相当条件では
両方の比較で明確に逆転し、momentumが優位になった（PIT: 1.530 vs 2.063、
full-history: 1.456 vs 1.787）。取引件数もdip-buyは3〜4倍に急増（359→1,208、
1,938→7,696）しており、想定していた「下落継続銘柄への繰り返しナンピン買い」が
大量発生していることを裏付ける。**この水準ではPhase1のGO判定の根拠は支持
されない**。

### (b) チョップ相場局面: 優位性は頑健に残存

同じ排他制御除去条件でチョップ相場局面のみを再集計したところ、dip-buy
PF=1.1811（黒字維持）・momentum PF=0.6414（Phase1自体の0.646とほぼ一致）と、
**Phase1の最重要発見（momentumの弱点をdip-buyが補完する）は排他制御と無関係に
頑健に残存**することを確認した。

## R14全体の判断への影響（重要・混在結果）

- 「全期間でdip-buyがmomentumを上回る」というPhase1のGO判定の一部の根拠は
  排他制御アーティファクトに依存しており、本番相当条件では支持されない
- しかし**最も重要な発見である「チョップ相場でのmomentum弱点補完」自体は
  頑健に残存**しており、R14全体を見送りとする必要はない
- **修正された価値提案**: dip-buyの適用シナリオを「常時稼働してmomentumを
  上回る独立戦略」ではなく、**「chop/レジーム検知下でmomentumを補完する
  レジームスイッチ型戦略」**として位置づけ直すべき。常時両方を同量で稼働
  させるとmomentum優位の局面でdip-buyの取引量急増が足を引っ張る可能性がある
  ため、何らかのレジーム検知（既存のmarket_regime判定等）で使い分ける設計が
  必要

## 推奨される次のアクション

1. **最優先**: dip-buyを常時稼働ではなく「レジーム検知連動型（chop/逆風検知時
   のみ有効化）」として設計し直すことをPhase 2設計に反映（現行Phase 2は
   SHADOW-ONLYで常時ログ収集中のため、本番影響はないが、将来の本番配線設計に
   必ず反映すべき）
2. 排他制御なし条件での「同一銘柄への累積エクスポージャー」を確認——本番では
   下落継続銘柄に資金を積み増し続けるリスクがあり、これはリスク管理上も
   重要な論点（既存のポジションサイジング・cluster capとは別に、同一銘柄
   への累積エクスポージャー上限が必要かもしれない）
3. 09-08のR14本番配線判断レビューでは、Phase 1のGO判定を額面通り受け取らず、
   「常時稼働ではなくレジームスイッチ型」という修正された前提で再評価すること
