# 投資システム：運用・採否判断の一枚メモ

**2026-10-28｜整理案・未決値あり**。機能の多さではなく、投資目的への寄与と維持負担で判断するための補助資料。正式ロードマップは既存R22、本書で工程・研究予算・売買設定は変更しない。

## 判断する六つのこと

| 論点 | 判断基準・整理案 | 現状 |
|---|---|---|
| **目的** | 「収益の上乗せ」「損失の抑制」「手作業の削減」を別々に評価する。何を最優先にし、何を犠牲にできるかを決める。 | 優先順位は未決 |
| **成功条件** | 同じ期間・資本・評価方法で費用後を比較。損失制御は必要なリスク低減と許容収益減で評価し、収益優位性とは別判定。主比較は既存のC11（損失制御案）対U（単純縮小）を維持する。テスト合格は利益改善の証明ではない。 | 比較方針は既存。必要効果・許容値・正式評価条件は未確定 |
| **資本・許容損失** | 研究上の基準額と実際の投入資金を分ける。通貨・評価期間と、口座／銘柄／相関グループの許容損失を明示する。想定ストップ損失を最大損失の保証にしない。 | 数値は未決。既存上限・停止条件は維持 |
| **総運用費・採算** | 売買費用に加え、データ・API・AI・サーバー・保守費と手作業時間を集計。比較先より追加でかかる費用に見合う便益かを判断する。初期研究費と今後の維持費は分け、売買費用は二重控除しない。時間は時間数で示し、金額換算する場合は単価を明示する。 | 本書では未集計。未把握をゼロとしない |
| **実行・監視の責任** | 成果物に担当・期限・入力版・完了証拠・失敗時対応を紐付ける。「実装済／配備済／実行済／効果確認済」を分ける。採用後の監視指標・停止／復帰条件も事前に定める。 | 担当・工程は既存計画を参照。全監視の稼働確認ではない |
| **継続・保留・打切り** | 継続は次に得る情報・工数上限・終了条件を伴う研究資源の判断。保留は不足証拠・再開条件・再確認日を付す。追加価値が示されない／維持負担に見合わない場合は打切り・簡素化を検討する。 | 既存方針を維持。研究打切りは全保有売却や機能停止の自動指示ではない |

## 未決事項の具体化

- **本人の選好が必要**：目的の優先順位、実資本の制約、許容損失・許容収益減など。数値は推定で埋めない。
- **エージェントが用意する材料**：実費・作業時間の把握可能範囲、同条件の比較結果、不足証拠、必要リスク低減・最低効果を含む判断値の具体案と単位・選択による差。資料作成と数値採用を区別する。
- **既存工程へ接続**：10/30の比較条件・残判断整理、11/06の候補別一次結論、12/04の研究継続判断へ渡す。全て2026年・JSTの既存レビュー目標で、新しい締切や自動実行予約は追加しない。入力不足でも一次結論は保留を含め提出する。

**境界**：P4全体は未完、正式前向き比較F1は未開始。隔離修正は配備完了ではない。研究継続・経済性合格・ブローカー準備・実資本投入は別判断。期待年率を本書から設定せず、現在の売買・停止・認証・通知設定は変更しない。
